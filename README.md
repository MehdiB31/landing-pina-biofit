# Pina Biofit — landing page

Site one-page, fichier unique `index.html` (images, logo et polices inclus).

## Mettre en ligne avec GitHub Pages

1. Sur github.com → **New repository** → nom : `pina-biofit` → Public → **Create repository**.
2. Clique **uploading an existing file**, glisse `index.html` (et ce README) → **Commit changes**.
3. **Settings → Pages** → Source : *Deploy from a branch* → Branch : `main` / `(root)` → **Save**.
4. Après 1–2 minutes, le site est en ligne sur `https://TON-PSEUDO.github.io/pina-biofit/`.

## Nom de domaine (optionnel)

Settings → Pages → **Custom domain** → entre ton domaine (ex. `pinabiofit.com`), puis ajoute chez ton registrar un enregistrement CNAME vers `TON-PSEUDO.github.io`.
